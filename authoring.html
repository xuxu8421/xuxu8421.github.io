THE USER PROBLEM

Generating text is only part of writing.

Creators can have plenty of information and still struggle to organize it. A generated draft can obscure the choices that led to its structure, making revision harder when the direction is wrong.

I designed an AI-assisted workflow that keeps ideas and their relationships visible: a topic graph leads to an editable outline, then to a draft. The goal was to make generation part of the creator’s working process.

PRODUCT DECISIONS

Put an editable structure between ideas and prose.

Constrain how ideas expand.

I led prompt design across association, structuring, overview, and drafting. Root-topic and child-concept constraints, self-ranking, and voting addressed uncontrolled expansion, unsupported ideas, and inconsistent hierarchies.

Let the creator revise the outline first.

I designed the Outline-to-Draft flow so users could change the structure before generating the full text and connect the resulting content back to its outline. That makes the intermediate representation a product control rather than hidden model output.

Make the generation stages testable.

I developed Python end-to-end scripts and split title and description generation into sequential model calls. This made the workflow’s stages explicit enough to compare prompt and model changes with regression cases.

EVALUATION LOOP

Judge the workflow across competing constraints.

I built a six-dimension quality rubric with stage-specific weights and an evaluation set organized around recurring content topics. I compared model combinations under quality, response-time, and API-cost constraints, using regression cases to check iterations.

The product lesson

The intermediate output is part of the user experience. A topic graph or outline is valuable when a creator can understand it, edit it, and use it to change what gets written next.
