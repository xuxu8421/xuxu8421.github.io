Generation task

Generating useful topic graphs

Topic graphs are intended to help an editor make sense of an unfamiliar subject. I wanted to test whether explicit hierarchy and sibling constraints could produce more useful directions than a single unconstrained response.

The project separated generation from evaluation: define the method, keep a baseline, repeat each condition, and inspect several quality dimensions rather than select only an attractive example.

DECISIONS

Evaluation design

Compare against one-shot generation

The generator creates root topics, expands branches with sibling context, and filters candidates. A one-shot method supplies a baseline for the same topics.

Resume interrupted runs

An asyncio runner bounds concurrency and saves each topic, method, and run separately. Existing outputs are skipped on restart; the client retries failed requests and recovers common JSON formatting issues.

Measure six dimensions of quality

A six-dimension rubric covers relevance, novelty, diversity, writability, objectivity, and readability. Three runs per method and topic are averaged before paired topic-level comparison.

IMPLEMENTATION

Experiment setup

30 stratified topics2 methods × 3 runs180 saved outputs6-dimension judge30 paired comparisons

The 30 topics span frequent, ambiguous, and abstract subjects. The experiment stores graph and score outputs separately and produces analysis tables and visualizations.

The reported means are calculated from all 180 saved score records, with each topic contributing equally to the comparison.

Results and limitations

Higher novelty, lower readability

Mean LLM-judged novelty rose from 3.23 to 3.87 / 5, and writability from 4.50 to 4.97 / 5. Readability fell from 4.99 to 4.52 / 5. These are evaluation scores, not user satisfaction or productivity measurements.

The generator and judge used the same model. The experiment used Chinese topics, without human ratings or component ablations. Those limits matter when interpreting the result.

Next experiment

Add blinded human review and an independent judge, then isolate the contribution of hierarchy, sibling context, and filtering. Test whether a constrained readability step preserves novelty.
